# Contributing to SentinelForge

Keep SentinelForge narrow: investigate a bounded incident, verify a minimal repair safely, require explicit approval, and record a durable audit trail. Run `pnpm check` and `pnpm test` before each pull request. Keep changes focused, test approval and verification changes, and do not introduce provider-specific calls into UI components.

Configure Qodo review before the first substantive integration PR, address substantive findings, and record deliberate exceptions in the PR discussion. Do not create artificial commits or reviews to imitate process.
